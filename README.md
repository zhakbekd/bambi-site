# BAMBI — Premium Travel & Meet Site

Премиальный сайт-визитка в стиле Luxury Travel с возможностью записи на встречу.

## 🚀 Быстрый старт

Просто открой `index.html` в браузере — или задеплой на GitHub Pages.

## 📁 Структура

```
bambi/
├── index.html     — вся разметка
├── style.css      — дизайн-система
├── script.js      — вся логика
└── README.md
```

## ✨ Возможности

- **Hero** с параллакс-эффектом и статистикой путешествий
- **Галерея** 6 городов (Париж, Бали, Дубай, Стамбул, Токио, Рим)
- **Запись на встречу** — 3 типа: Парень ❤️ / Друг 🤝 / Подруга 🌸
- **Встроенный календарь** с датами свободно/занято
- **Выбор времени** слотами
- **Таблица встреч** с поиском и сортировкой
- **LocalStorage** — данные сохраняются между сессиями
- **Тёмная / светлая тема**
- **Прелоадер** с анимацией
- **Toast-уведомления**
- **Валидация форм**
- **Адаптивность** (mobile-first)

## 🌐 GitHub Pages

1. Создай репозиторий на GitHub
2. Загрузи все файлы
3. Настройки → Pages → Source: main branch / root
4. Готово!

## 🎨 Дизайн

- Шрифты: Cormorant Garamond + Jost + Dancing Script
- Палитра: бежевый #c9a87c, кремовый #faf6ef, песочный #d4b896
- Glassmorphism-карточки
- Плавные анимации на CSS + Intersection Observer
